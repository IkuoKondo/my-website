From Our Team

Payment Technologyは「世界の企業と人にイノベーションを」をミッションに掲げ、HR事業（エニジョブ）と給与事業を通じて、日本の労働市場が抱える構造的な課題に挑んでいます。

私たちが向き合っているのは、人口減少・スキマバイトの台頭・採用コストの高騰という、あらゆる企業が直面する切実な課題です。エニジョブは採用を「消費」から「資産の蓄積」へと変えるプラットフォームとして、すでに25社以上に導入されています。

事業フェーズとしては、今が最も重要で、最も面白い時期です。少数精鋭のチームで大きな課題に向き合い、自分の仕事が事業に直接インパクトを与える環境があります。「ここで働くことが自分のキャリアにとって誇りになる」——そう感じられる人と一緒に働きたいと思っています。

Values

私たちが大切にしていること

Core Values

VALUE 01
スピードと実行力

考えることと動くことを同時にやる。不確実な状況でも仮説を立て、検証し、改善し続ける。一人ひとりの行動が事業を直接動かします。

VALUE 02
社会課題への真摯な向き合い

日本の人材不足・採用コスト問題という構造課題に向き合う。事業の成功が社会課題の解決に直結する、このミッションに本気で共鳴できる人と働きたい。

VALUE 03
データと論理で語る

「なんとなく」ではなく数字と根拠で意思決定する。感情論ではなく、ロジックと事実で議論できる文化を大切にしています。

VALUE 04
オーナーシップ

担当領域を自分ごととして責任を持つ。指示を待つのではなく、自ら課題を見つけて提案する。スタートアップだからこそ、裁量を持って仕事ができます。

VALUE 05
グローバルな視野

ミッションは日本に留まりません。国内で実証したモデルを世界の労働市場にも展開することを見据え、事業を設計しています。

VALUE 06
相互リスペクト

役職・年次を問わず意見を尊重し、建設的に議論できる組織文化。誰でも正直に意見を言える心理的安全性を大切にしています。

Culture

チームのカルチャー

How We Work

Core Belief
採用を「消費」から
「資産の蓄積」へ

エニジョブが解決しようとしているのは、採用の構造そのものです。私たちはこのミッションを、プロダクト・セールス・マーケティングのあらゆる角度から推進しています。毎日の仕事が、直接このビジョンの実現につながっています。

Speed
意思決定が速い

少人数チームだからこそ、ミーティングで合意してその日のうちに実行できる。提案から実装まで、大企業では考えられないスピードで動きます。

Ownership
担当領域は自分の事業

「あの機能を作ったのは自分」「あのクライアントを口説いたのは自分」——自分の仕事がプロダクト・数字に直接残る環境があります。

Growth
急速に学べる環境

成長フェーズのスタートアップは、経験が圧縮されます。1年で大企業の3〜5年分の意思決定経験を積めると多くのメンバーが話しています。

Mission
仕事が社会課題と直結

人材不足に悩む企業が採用コストを削減できた。そのインパクトを数字で見ながら働けることが、チームの最大のモチベーションになっています。
